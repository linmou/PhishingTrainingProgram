# Cyberbullying rooms

## Description

In a cyberbullying room the learner writes about a pinned scenario, the server judges against five shared learning targets, and the room owner replies through reviewed character drafts that every participant sees under the same character.

## Outcome

For anyone changing the cyberbullying practice or adding a practice type: what is specific to this practice is written once.

## Boundaries

- Touch point: progress states belong to epic-learning-progress; tutor review and send belong to epic-ai-suggestions; room creation belongs to epic-rooms-and-templates.
- Not here: transfer assessments and Quick Adjust, which cyberbullying rooms refuse.
