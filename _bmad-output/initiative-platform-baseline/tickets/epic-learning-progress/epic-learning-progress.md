# Learning targets and progress

## Description

Learners have learner-owned learning targets. Each learner message is judged against each target on the server. Progress moves only through the defined states and events, is shown to the room owner, and can be corrected by hand by the owner.

## Outcome

For anyone changing how learning is judged or recorded: the states, events and single-writer rules are written once.

## Boundaries

- Touch point: Guard pausing progress belongs to epic-supervision-and-guard; transfer assessments that change progress belong to epic-transfer-assessment; the five cyberbullying targets belong to epic-cyberbullying-rooms.
- Not here: the quality of AI judging, which the AI behavior specifications govern.
