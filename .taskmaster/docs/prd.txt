I want to build an online Tutor system that support 1v1 tutor student training. 

Here are some features: 
    When a user logging in, she can choose student, tutor or observer.
    Limited capacity: only one user, one tutor at a time. If there is one user or tutor logged, others can not logged as student or tutor.
    For Tutor, they can create a room, so that other users can go into the room. For each room, teacher can write a paragraph of words and upload a picture. 
    For student and observer, they can choose the room to go into. If there is no room created, they should wait. show a message to ask them to wait.
    Once entering the room, tutor and students can chat there. observer can only watch.
    Add a function for all users to download the chat history, and room info.
