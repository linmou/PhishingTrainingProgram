## Production-parity limits

Independent review corrected the original description of the 100-token/0.3 configuration. The frozen settings and raw snapshots are preserved; their `changed_factors` prose calling it a production default is superseded by the distinction above. This is a controlled prompt comparison with production builder/parser/format-repair behavior. It does not estimate default-room performance or production transport reliability: the evaluation permits three provider transport attempts, while the actual client/Edge path propagates provider failures. Saved cases also omit the live caller's checklist-progress enrichment and optional verified-assessment feedback. Those contexts and the deployed model identity require real product-path verification before release.
